# Joybuy---Online-Shopping
     JoyBuy is a user-friendly shopping app that allows customers to browse, purchase, and track orders easily from their mobile devices. It also provides sellers with tools to manage products and inventory efficiently through the admin system.
---

## Features

### Customer Features:
- Browse a wide variety of products with ease.
- Add products to the cart and make secure payments.
- Track order status and view order history.
- Beautiful and responsive UI for smooth navigation.

### Admin Features:
- Manage product listings, including adding, editing, or deleting products.
- View inventory details and track product stock levels.
- Handle customer orders efficiently.
